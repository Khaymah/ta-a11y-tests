# سيناريوهات الاختبار اليدوي — منصّة «طا»

الاختبارات الآلية مش بتحكم على **التجربة نفسها**. السيناريوهات دي بتتعمل بإيد بني آدم، والأفضل يعملها مستخدم فعلي من ذوي الإعاقة.

## الأدوات

| الأداة | المنصة | التشغيل |
|---|---|---|
| **NVDA** (مجاني) | ويندوز + Chrome أو Firefox | `Ctrl+Alt+N`. فعّل الصوت العربي من الإعدادات ← الكلام |
| **VoiceOver** | ماك + Safari | `Cmd+F5`. الـ rotor بـ `VO+U` |
| **VoiceOver** | آيفون | الإعدادات ← تسهيلات الاستخدام ← VoiceOver |
| **TalkBack** | أندرويد | الإعدادات ← تسهيل الاستخدام |
| تباين عالي | ويندوز | `Alt+Shift+PrintScreen` |
| تكبير | أي متصفح | `Ctrl` + `+` لحد 400% |

---

## 1. مكفوف بيذاكر «تحفة الأطفال» (NVDA)

1. افتح `/modules/tuhfah` من غير ما تبص على الشاشة.
2. اضغط `H` للتنقل بين العناوين. **المتوقع:** يسمع أسماء الأبواب بنطق عربي سليم.
3. افتح «المقدمة» بالكيبورد.
4. اقرا أول بيت بالأسهم. **راقب:**
   - [ ] البيت بيتقري **متصل** ولا كلمة كلمة؟ (كل كلمة جوه `span` لوحدها)
   - [ ] التشكيل بيتنطق صح ولا بيقول أسماء الحركات؟
   - [ ] رقم البيت بيتقال قبل البيت؟
5. شغّل التلاوة من المشغل. **راقب:**
   - [ ] بيعرف إن التشغيل بدأ؟
   - [ ] بيعرف البيت اللي بيتقري دلوقتي من غير ما يشوف؟
   - [ ] لما البيت يتغير، NVDA بيقرا الصفحة كلها؟ (`section.content` عليه `aria-live`)
6. علّم بيت إنه «محفوظ». **المتوقع:** يسمع «تعليم كمحفوظ، مضغوط» أو تأكيد إن الحفظ اتسجل.

## 2. مكفوف بيقرا من المصحف (VoiceOver)

1. افتح `/modules/masahif/sughra`.
2. حاول توصل لنص الفاتحة. **المتوقع حالياً:** مش هيوصل، لأن الصفحة صورة.
3. غيّر الصفحة. **راقب:** [ ] بيعرف هو في صفحة كام وسورة إيه؟
4. جرّب خانة نسبة التكبير. [ ] اسمها واضح؟ [ ] بيعرف القيمة الحالية؟

## 3. مستخدم كيبورد بس (إعاقة حركية)

1. افصل الماوس.
2. من الرئيسية: [ ] توصل لـ «الشاطبية» بأقل عدد Tab؟ [ ] تشوف فين الـ focus طول الوقت؟
3. في صفحة متن: [ ] تفتح باب، وتشغّل بيت، وتعلّمه محفوظ، وتعمل «اختبار الباب» للآخر بالكيبورد بس؟
4. في الاختبار: [ ] فيه حد زمني؟ ينفع يتمد؟
5. افتح أي قائمة أو نافذة. [ ] `Esc` بيقفلها؟ [ ] الـ focus بيرجع للزرار اللي فتحها؟

## 4. ضعيف البصر

1. كبّر المتصفح 200% ثم 400%. [ ] مفيش نص بيتقص أو بيركب على بعض؟ [ ] المشغل لسه ينفع يتستخدم؟
2. فعّل التباين العالي في ويندوز. [ ] الأزرار والأيقونات لسه باينة؟ [ ] الـ focus باين؟
3. غيّر حجم الخط الافتراضي في Chrome لـ «كبير جداً». [ ] نص الأبيات كبر؟

## 5. أصم أو ضعيف السمع

1. افتح «شرح الباب». [ ] الفيديو عليه ترجمة عربية دقيقة (مش آلية)؟
2. [ ] أي معلومة بتيجي بالصوت بس (زي صوت إجابة صح أو غلط) ليها بديل مكتوب؟

## 6. صعوبات تعلم أو تشتت انتباه

1. [ ] تقدر توقف أي حركة؟ [ ] التعليمات في الاختبار واضحة وبسيطة؟
2. [ ] رسائل الخطأ بتقول تعمل إيه؟ [ ] التنقل ثابت في كل الصفحات؟
